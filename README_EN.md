# Meizu 16th Plus: Debian 13 + Plasma Mobile

[简体中文](README.md) | English

Community mainline Linux support for the Meizu 16th Plus (Fastboot product
`M1892`, Snapdragon 845), using Debian 13, Plasma Mobile, systemd and Freedreno.
Other Meizu models are not supported.

**This branch currently publishes source. There is no Debian installation bundle
that has passed the latest complete fresh-install validation.** Do not combine
postmarketOS Release images with this branch. A validated bundle, its matching
installer and checksums will be linked here when available.

- [Features and limitations](KNOWN_ISSUES_EN.md)
- [Installation and recovery](INSTALL_EN.md)
- [Source and build reproducibility](BUILD_EN.md)
- [Privacy and firmware](PRIVACY_EN.md)
- [Existing postmarketOS line](https://github.com/NoobMaster233/meizu-m1892-mainline-linux/tree/main)

One 128 GB device has test evidence for the desktop, touch, hardware graphics,
rotation, Wi-Fi, Bluetooth, LTE data, SMS, call audio, media playback and recording,
USB Host and Docker. These live-device results do not establish that this source
snapshot has passed another complete installation. There is no second-device or
64 GB hardware validation, and Android-equivalent reliability and battery life
are not claimed.

Owners create an account during initial setup. Public content contains no owner's
accounts, passwords, SSH keys, Wi-Fi profiles, unique device identifiers, games,
Steam library or application sessions. GPU overclocking and undervolting remain
device-specific experiments; the public default stays at 710 MHz.
